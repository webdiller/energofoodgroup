## Как выгрузить изменения?
Вызываешь команды:
```bash
npm run check:build - Ожидаешь, что не будет ошибок. Если есть пробуешь исправить или набираешь меня
git add .
git commit -m 'update'
git push
npm run deploy
```
Через 20 секунд примерно обновляешь страницу в браузере с новыми изменениями `https://webdiller.github.io/energofoodgroup/`
